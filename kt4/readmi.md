# BEM Layout Example

## Что здесь происходит

В этом примере показана простая карточка, сверстанная с использованием методологии БЭМ (Блок, Элемент, Модификатор).

## Структура

- block: `card`
- elements:
  - `card__title`
  - `card__description`
  - `card__button`
- modifiers:
  - `card__button--primary`
  - `card__button--secondary`

## Как это работает

- Блок (`card`) — независимый компонент.
- Элементы (`__`) — части блока, которые не используются отдельно.
- Модификаторы (`--`) — изменяют внешний вид или поведение.

## Зачем это нужно

- Удобная масштабируемость
- Понятная структура классов
- Минимум конфликтов стилей

## Как использовать

1. Создаёшь блок
2. Внутри описываешь элементы через `__`
3. Добавляешь модификаторы через `--` при необходимости

Пример:

```html
<button class="card__button card__button--primary"></button>
```
